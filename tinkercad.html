You are the airport electrician.
Build the lights that save planes.

In the game you flew by reading 4 lights. Now you build those exact 4 lights, plus a knob that pretends to be the aircraft, using an Arduino in Tinkercad. At the end, your circuit will print the same angle and verdict that the game shows.

Part 3The code (copy and paste)

  1. In Tinkercad click the Code button (top right).
  2. Change the drop-down from Blocks to Text. Click Continue when it warns you.
  3. Click inside the code box, press Ctrl+A to select everything, then Ctrl+V to paste over it.
/* MSN 02 - PAPI Runway Approach Lights
   The knob is the aircraft's glide angle. Four units, each with a white and a red LED. */

const int GLIDE_KNOB = A0;                  // potentiometer wiper
const int WHITE_PIN[4] = {2, 4, 6, 8};      // white LEDs: unit 1, 2, 3, 4
const int RED_PIN[4]   = {3, 5, 7, 9};      // red LEDs:   unit 1, 2, 3, 4

// Unit 1 is nearest the runway. Each unit turns WHITE once you are above its own angle.
const float UNIT_ANGLE[4] = {3.50, 3.17, 2.83, 2.50};

void setup() {
  Serial.begin(9600);                      // open the Serial Monitor line
  for (int i = 0; i < 4; i++) {
    pinMode(WHITE_PIN[i], OUTPUT);
    pinMode(RED_PIN[i], OUTPUT);
  }
}

void loop() {
  int raw = analogRead(GLIDE_KNOB);          // 0 to 1023
  float angle = raw * (6.0 / 1023.0);        // 0 to 6 degrees
  int whiteCount = 0;

  for (int i = 0; i < 4; i++) {
    bool above = angle > UNIT_ANGLE[i];      // am I higher than this unit's angle?
    digitalWrite(WHITE_PIN[i], above ? HIGH : LOW);
    digitalWrite(RED_PIN[i],   above ? LOW : HIGH);
    if (above) whiteCount++;
  }

  Serial.print("Angle: ");
  Serial.print(angle, 2);
  Serial.print(" deg | white lights: ");
  Serial.print(whiteCount);
  Serial.print(" | ");

  if (whiteCount == 4)      Serial.println("TOO HIGH - white on white, check your height");
  else if (whiteCount == 3) Serial.println("SLIGHTLY HIGH");
  else if (whiteCount == 2) Serial.println("ON SLOPE");
  else if (whiteCount == 1) Serial.println("SLIGHTLY LOW");
  else                      Serial.println("TOO LOW - red on red, you're dead");

  delay(200);                              // 5 updates per second
}

Pasted but errors? Make sure you selected all the old code before pasting, and that the editor says Text, not Blocks.

What each important line does

const float UNIT_ANGLE[4]An array: four numbers under one name. Each PAPI unit has its own angle, so together they make a ruler for the slope.
analogRead(GLIDE_KNOB)Measures the voltage on A0 and gives a number from 0 (0 V) to 1023 (5 V).
raw * (6.0 / 1023.0)Scales 0–1023 into 0–6°. Double the reading, double the angle. That is direct proportion from maths.
for (int i = 0; i < 4; i++)Repeats the same instructions for units 0, 1, 2, 3. In ICT this is called iteration. 4 units, 1 loop, no copy-paste.
above ? HIGH : LOWShort if/else. If above is true give HIGH (LED on), otherwise LOW (LED off).
RED... above ? LOW : HIGHThe red is the opposite of the white. Exactly one of the pair is on at any time, like a real PAPI.
Serial.print(angle, 2)Prints the angle with 2 decimal places in the Serial Monitor.

Part 5Run it and test it

  1. Click Start Simulation. Then click Serial Monitor at the bottom of the code panel.
  2. Click the potentiometer once. A small slider pops up. Drag it slowly.
  3. Fully one way: all four units show red (TOO LOW). Fully the other way: all four show white (TOO HIGH).
  4. Around the middle: 2 white + 2 red, angle about 2.9° to 3.1°, and the monitor says ON SLOPE.
  5. Watch the units flip one at a time, starting with unit 4.

Part 7Boss levels

Boss 1 · The alarm

Add a Piezo buzzer that beeps faster the further you are from 3°. (Hint: you need abs(angle - 3.0), and tone().)

Boss 2 · No decimals

Rewrite the code with map() and whole numbers in tenths of a degree (0–60) instead of floats.

Boss 3 · Height coach

Use your trig. Work out the correct height at 1 km and at 500 m. Make the Serial Monitor print the “correct height” for a fixed distance.
